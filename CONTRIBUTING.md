# Contributing

Use English and avoid em dash characters. Keep commits focused and use your own
Git author identity. Run formatting, lint, strict typing, tests and report replay
before proposing a change. Add tests for behavioral changes and malformed inputs.

Never tune on the frozen held-out split or overwrite published results. Add a new
versioned dataset and protocol for changed experiments. Preserve failed outputs,
model hashes, implementation provenance and measurement limitations. Use local
hardware only. In the coordinated project environment, use the shared exclusive
benchmark wrapper for every heavy run. Do not modify sibling projects.
